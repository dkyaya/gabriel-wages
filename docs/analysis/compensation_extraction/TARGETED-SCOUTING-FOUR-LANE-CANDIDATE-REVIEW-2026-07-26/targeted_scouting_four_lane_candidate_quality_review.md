# Four-lane candidate quality review

The deterministic metadata review scored all 4,228 candidate-only rows on ten fixed dimensions totaling 100 points: source specificity, mechanism relevance, same-city match value, cycle value, unit clarity, source-family strength, duplicate risk, prior-seen status, verification feasibility, and claim-gap contribution.

Quality counts: `{'deprioritize_this_phase': 17, 'repair_or_review_needed': 737, 'verification_ready_high': 142, 'verification_ready_low': 2049, 'verification_ready_medium': 1283}`. Scores range from 48 to 98. A low or missing metadata field reduced the score; no missing value was fabricated. Scores predict verification priority only. They do not establish locator liveness, document identity, source validity, or evidentiary quality.
