# Unsupported claims

- **A national safety wage-gap estimate** — Matched city-cycle breadth and harmonized pay basis are insufficient.
- **A national prevalence estimate for any mechanism** — Evidence-unit counts are not population-weighted denominators.
- **A causal effect estimate of a mechanism** — No counterfactual identification design or treatment-effect analysis was run.
- **A regression-based claim** — No regression was run or authorized.
- **A precise claim that safety wages grow X percent faster** — Global wage-gap readiness fails.
- **The mechanism caused an observed wage difference** — Documentary mechanism interpretation is not causal estimation.
