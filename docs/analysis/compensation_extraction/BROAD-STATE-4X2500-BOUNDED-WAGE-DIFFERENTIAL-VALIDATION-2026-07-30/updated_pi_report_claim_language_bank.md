# Updated PI-report claim language bank

## Use

- “Bounded local documentary evidence in the matched municipality-cycle candidate shows …”
- “On the current normalized basis …”
- “The source lists a maximum rate,” where applicable.
- “Requires manual, legal, or substantive validation before analytic use.”

## Avoid

- “The wage gap is …”
- “Safety workers earn X% more” without the municipality, period, rate type, and documentary boundary.
- National, prevalence, policy-effect, treatment-effect, or causal language.
