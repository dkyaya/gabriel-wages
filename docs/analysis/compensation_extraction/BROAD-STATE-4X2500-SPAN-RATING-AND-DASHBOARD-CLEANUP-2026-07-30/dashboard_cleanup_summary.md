# Dashboard cleanup summary

The dashboard now presents a PI-facing evidence brief rather than a pipeline monitor. Its main view contains one current-status strip, the scout-coverage-rate map, four rating-state figures, a six-row mechanism preview, a compact claim-boundary panel, and one next task. Technical reconciliation and historical stage counts are collapsed by default and remain reconstructible from the linked report.

The map remains exclusively a scout-coverage map. Color uses scout-covered municipalities divided by the eligible or known municipality universe; raw covered and denominator counts remain contextual. No source-family, candidate, evidence, mechanism, or readiness filter controls map color.

The cleanup removes equal visual weight from obsolete stage counters, hides implementation detail from the initial view, and makes the evidence boundary explicit: descriptive documentary summaries are allowed, wage comparisons await normalization, and causal claims await matched city-cycle structure.
