# Global readiness blockers

- **normalization** (blocking): 10,109 quantitative records need unit/period/rank/step/base-status normalization; zero were normalized.
- **matched_structure** (blocking): Same-city, same-cycle safety/non-safety unit matching has not been constructed for these records.
- **causal_design** (blocking): Temporal ordering, confounding strategy, and design diagnostics are incomplete.
- **representativeness** (caveat): The 49-state corpus is broad but convenience-sourced and uneven; it is not a population sample.
- **source_family_geography_balance** (caveat): State, region, source-family, and exact-CBA composition are uneven.
- **weak_context_volume** (caveat): 5,080 dashboard records are weak, context-only, or unsupported and remain separated.
