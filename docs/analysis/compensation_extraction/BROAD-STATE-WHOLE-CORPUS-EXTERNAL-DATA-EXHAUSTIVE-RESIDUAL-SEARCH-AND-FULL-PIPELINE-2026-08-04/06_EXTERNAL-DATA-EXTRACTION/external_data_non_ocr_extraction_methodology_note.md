# External-data non-OCR extraction methodology

Readiness produced 14,257 extraction-ready unique physical payloads. Five independent local lanes processed each payload once; exact duplicates and prior-source reuse links did not create duplicate work. PDF text came only from existing text layers, and HTML was parsed locally without JavaScript, browser automation, crawling, or network access. Full text and structured records are compressed per source under Git-ignored storage, while Git receives hashes, counts, schemas, bounded metadata, pointers, and lineage. Page, section, table, row, column, source, candidate, event, and claim lineage is retained. No OCR, hosted search, GABRIEL scoring, redownload, substantive field interpretation, normalization, matching, claim reassessment, or implementation-event deduplication occurred. The 12,844 search gaps and 7,895 storage-capacity holds remain preserved. Extraction establishes machine-readable content, not evidentiary truth.
