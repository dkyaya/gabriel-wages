# Clean-room acceptance test plan

1. clone fresh Git history into a clean directory.
2. install from pinned environment instructions.
3. run all compact validation scripts.
4. reproduce claim and headline tables from compact inputs.
5. render approved figures and compare checksums or bounded values.
6. serve barebones dashboard locally.
7. resolve source-library pointer and verify canonical source checksums.
8. verify no absolute current-machine path is required.
9. verify no secret or credential is included.
10. verify archive bundle and restore instructions.
11. accept only after another operator completes the workflow without the original working tree.
